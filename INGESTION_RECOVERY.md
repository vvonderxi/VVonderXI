  - **THE LIVE IMPORTER GUARDS (all thresholds in one block at the top of the guards section in `api/import-players.js` , that file is the source of truth, this is the map).** Classify same-league blocks after dropping 0-min phantoms: 0 real -> skip; 1 real -> take it; >=2 real -> ARTIFACT (dedupe to max-minutes, **NEVER sum** , summing doubles: Cunha 15g -> 30g) vs GENUINE split (sum goals+assists+minutes, team_name = dominant club). 300-min floor applies to the RESULT, not block[0]. Artifact tests: season-DERIVED apps/minutes ceilings (never a static constant , BPL runs to 45 apps, TR changes size by season) + near-mirror + **exact minute equality regardless of appearances** (a measured copy signature, 3/3 perfect association). Plus two duplication nets: **(a) PROPORTIONALITY GATE** (Poisson upper tail vs an elite ceiling, `CEIL_G90=1.00`/`CEIL_A90=0.60`/`P_IMPLAUSIBLE=0.01`, **richest block EXEMPT** so a genuine elite season is never gated for being too good); **(b) PER-STAT DUPLICATION GUARD** requiring BOTH shared nonzero stat `>=MIN_SHARED_STAT=3` AND minute ratio `>=MIN_MIN_RATIO=0.5`.
  - **RULE FOR ANY FUTURE RE-INGEST , INSERT-ONLY, ALWAYS.** The importer's default write is `upsert(onConflict:api_player_id,season,league_code)`, which REWRITES existing rows; since the view recomputes rt from goals+assists, that shifts existing scores. Use `ignoreDuplicates:true` (ON CONFLICT DO NOTHING) + bypass/clear the `isSeasonDone` checkpoints (a plain re-run does nothing otherwise), then REFRESH MATERIALIZED VIEW. Cost reference: a full 9-league pass is ~3,500-4,500 API-Football calls (~5-6% of the 75k budget), ~1-2h wall.
  - **METHOD CORRECTION , do NOT screen a dry run on the importer's `rt > 85` eyeball.** The importer's `ratingToRt` is API-match-rating based and diverges wildly from the view's output-driven rt (it flagged Clauss 89 -> view 72 and Doue 87 -> view 69 while MISSING Lepaul, the one card that actually landed in World Class). **Screen on PREDICTED OUTPUT (goals+assists vs minutes), and screen OUTFIELD ONLY** , the output proxy fails badly on GKs (Turati predicted 25, actual 74) but that is harmless, since GK is capped at 75 and can never reach the flag line.
