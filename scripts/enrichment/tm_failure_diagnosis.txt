4. VERDICT
   NOT one cause. Four distinct ones:
     a) CLUB ALIAS      8 cards  Bayern München -> TM "Bayern Munich"; the matcher took the
                                 longest word ("München") which does not appear at all.
     b) NAME ORDER      2 cards  Son Heung-Min; TM indexes Korean names given-name-first.
     c) NETWORK        14 cards  ALL 14 "parse" failures are fetch errors, not parse errors:
                                 11 TimeoutError + 3 TypeError. Zero reached the parser.
                                 The run also logged 1x 429. TM was degrading under load.
     d) MY ABORT LOGIC  , the roll window recorded id:!!picked, and a network exception
                          leaves picked=null, so all 14 network errors were counted AS
                          identity failures. That is why it aborted at "19%" when true
                          identity failure was 10%. The abort was partly spurious.

5. THE FIX IS NOT AN ALIAS MAP
   230 distinct clubs in the 3,891-card target set. 24 look risky by inspection, but for
   22 of them the matcher token IS a substring of TM's name (Tottenham c Tottenham Hotspur,
   Napoli c SSC Napoli). Only TWO genuinely break, covering 128 cards:
     Bayern München  -> token "München" vs "Bayern Munich"
     Atletico Madrid -> token "Atletico" vs "Atlético de Madrid" (accent)
   Simulated against 14 known TM forms: current matcher fails 2, proposed fails 0.
   PROPOSED: accent-fold both sides, and match on ANY word >=4 chars rather than the
   longest one. That fixes Bayern (matches "Bayern") and Atletico (folds the accent),
   and needs no hand-maintained alias list that would rot as club names change.
