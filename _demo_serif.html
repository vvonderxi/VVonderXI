the FOUT , what the reflow does to the most-read block

This panel starts in the fallback and swaps to Fraunces on the button, measuring itself before and after. It is a metric swap, not a network simulation, and that is deliberate , the first version of this fetched the stylesheet and reported "no reflow", because Fraunces was already CACHED from another demo on this origin. A warm cache is precisely the state in which a FOUT cannot be seen, so that test could only ever pass. The reflow below is the one a first-time visitor gets, and it is the same number either way.
